系統評核指引與使用提示

1. 本地教學模式：留空 API Key 即可使用內建專業評審邏輯與示範資料，點擊右上角「一鍵載入示範手稿與評審結果」即可演示。

2. 橫向程度按鈕：每項指標均設有 6 個橫向水平按鈕，老師或學生可直接點選調整，雷達圖與整體評級會即時連動。

3. 雙向回饋：每項指標分為「a. 欣賞之處」與「b. 不足之處及改善意見」兩組獨立可編輯文字方塊，方便因材施教。

4. 去數值化：完全不顯示阿拉伯數字總分，依內部權重自動換算為「卓越、熟練、基礎/達標、部分達標，但表現不夠穩定、尚未掌握核心能力」。
